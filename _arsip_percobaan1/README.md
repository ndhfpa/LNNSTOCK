# Arsip Percobaan 1
Direktori ini digunakan untuk mengarsipkan file percobaan lama (CRUD Data Pengguna tanpa login dan 1 tabel) agar workspace bersih sesuai arahan dosen.
Proyek LNNSTOCK baru dibangun bersih dengan arsitektur MVC Native, PDO, Multi-tabel, Login Auth, dan desain UI berstandar industri.
